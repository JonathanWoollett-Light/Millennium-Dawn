# Devolution Mechanic:
# Agitation = how annoying they are, basically, higher agitation means more harsher punishments for when they go against you
# -------------- HOW AGITATION WORKS -------------- #
# [-] Agitation will grow from certain focuses/events/decisions etc
# - Agitation will be lowered over time naturally
# - If you maintain a high level of agitation for a while, you'll get random events that increase nationalism
# - Coupled with random naitonalism events, you get debuffs anytime they are pissed
# - If nationalism is above 85% for too long, Agitation will start growing randomly anywhere between 1-3 every month
# - Agitation can be lowered by a lot by lower their dependency
# -------------- HOW DEPENDENCY WORKS -------------- #
# [-] Dependency is lower or increased via the focus tree (A Variable out of 100 with 3 stages)
# - In the focus tree, there will be 2 trees, 1 for pro-devolve and 1 for against per region
# - The paths are made available based on party ideology
# - Focuses will unlock decisions that count as laws that you could pass (Either pro or anti devolution laws)
# - Some of these decisions are permanent/irreversable laws, EX: Reducing Scottish parliament seats (Will get to this later)
# - Will have 1 for Scots, Welsh, and Irish
# --- Government Change in the middle of devolution ---
# [-] Gives Spirit "Promises of Devolution"
# --- What if you change governments from anti-devolution party to pro-devolution? --- #
# - After change of govt. If you already went down dickstomping devolution, it gives you an event that pops up and says:
# "Scottish seats will support you if you revert the fuck up of previous administration" (Halting Devolution). If you say accept,
# But continue devolved policies, then the Scots agitation will increase by 2X anytime they get pissed (EX: 1 agitation is now 2)
# But if you keep your promise, it will bring their agitation down and you get support from them.
# You will also get decisions to repeal certain laws that will decrease their dependency on the U.K.
# If you reject their request, you can just go down the devolution path the previous admininistration started
# If you for some reason bring back the anti-devolution party, you then get those laws (decisions) you got from focuses
# You will NOT get the decisions for the permanent decisions, this goes for both pro and anti devolution parties
# --- What if you change governments from pro-devolution party to anti-devolution? --- #
# - Gets event that lets you make a promise that you won't clamp down on progress made on devolution
# - You will be able to repeal certain laws as stated from before, as mentioned before if you decide to clamp down
# If promise is granted and you don't reverse devolution, agitation will decrease BUT it will give an equilibrium toward devolution
# If you decide to continue going the route of dick-stomping devolution, then you will start losing party popularity
# Dependency levels will decide independence levels
# - Dependent is when the constituent is in your land (not on the game map)
# - Semi - Dependent is any of the 4 autonomy levels (on the map, but they are a puppet)
# The autonomy levels will dynamically shift as the player goes deeper into devolution
# Idea is to encourage as low as possible on devolution to maximize bonuses towards the player
# Bonuses include %'s of GDP and Commonwealth nation member states which will ultimately help the U.K.
# Will also give option to force Wales & Northern Ireland to use the British Pound
# - Independent is idk take a wild guess
# -------------- HOW NATIONALISM WORKS -------------- #
# [-] Nationalism will decide whether or not the constituent will declare a referendum
# - Nationalism will grow upon doing moves that anger the constituent
# - Possible causes for nationalism are:
# Certain events/focuses/decisions that may cause harm to that constituent
# Beginning to back peddle on devolution or trying to curb it entirely
# Going to War
# - If nationalism hits 100, they will run a referendum that you then have to ratify
# Agitation will decide their reaction to your decision on referendum
# Low agitation if Rejected: non-violent protest movements (damage to economy basically)
# high agitation if rejected: Car bombings every other day & chance of revolt upon rejection (car bombings still follow)
# Low agitation if accepted: Devolve with a lot of control (This is basically outcome if u just do everything to devolve)
# High agitation if accepted: Devolve with less control (this is if they hit u w/the referendum and u accept)
# -------------- Focus Tree -------------- #
# Once someone goes down the path of either devolving or not, if they decide to nothing and edge the system, they'll get devolution fallout spirit x10
# -------------- MISC -------------- #
# [-] Add game rule that lets you spell Scotland will let you spell Scotland with 2 T's
# - If made available, all your leaders and generals get renamed to "Scott"

# Divide 650 by party pop by each slot
# Wales and scotland: Take Party Pop, but then you take away the nationalists % Variable and then the remainder of the % left are given to the nationalist parties
# - Change the GUI for NIR to split nationalism into 3 bars, Unionism, Non-Sectarianism, & Republicanism
# - Make 3 seperate variables.
# If you go against devolution you support unionists
# If you go further devolution you can support the Republicans & Non Sectarians
# These 3 seperate variables will decide end state for NIR
# 18 NIR Seats, and take 3 variables and divide them against 18 (Based on actual variables)
# 59 Scottish (Based on actual nationalism VAR)
# 40 Welsh (Based on actual nationalism VAR)
# Whoever wins the election loses one seat as they get a speaker
# English seats: (Take Party Popularity variable) (if minor -, if major +) ( random variable selected from range of 0-10)
# (Take Party Popularity of Labour,Tories,LibDems,Greens) (then Combine) (then add Nationalist Percentage) (remainder randomly distributed)

ENG_north_irish_agitation_change_check = {
	if = {
		limit = {
			OR = {
				17 = { has_dynamic_modifier = { modifier = ENG_State_17_Paramilitary_Activity } }
				ENG = {
					has_idea = ENG_the_dissident_campaign
					has_idea = ENG_good_friday_agreement
				}
			}
		}

		if = {
			limit = { ENG = { has_idea = ENG_good_friday_agreement } }
			set_variable = { ENG_agitation_penalty_mult = 0.8 }
		}
		else = {
			set_variable = { ENG_agitation_penalty_mult = 1.0 }
		}

		if = {
			limit = {
				check_variable = { ENG_north_irish_agitation > 0 }
				check_variable = { ENG_north_irish_agitation < 15 }
			}
			set_variable = { ENG_Paramilitary_state_productivity_growth = -0.05 }
			set_variable = { ENG_Paramilitary_local_factory_sabotage = 0.10 }
			set_variable = { ENG_Paramilitary_required_garrison = 5 }
		}

		else_if = {
			limit = {
				check_variable = { ENG_north_irish_agitation > 14 }
				check_variable = { ENG_north_irish_agitation < 30 }
			}
			set_variable = { ENG_Paramilitary_state_productivity_growth = -0.15 }
			set_variable = { ENG_Paramilitary_local_factory_sabotage = 0.15 }
			set_variable = { ENG_Paramilitary_required_garrison = 10 }
		}

		else_if = {
			limit = {
				check_variable = { ENG_north_irish_agitation > 29 }
				check_variable = { ENG_north_irish_agitation < 45 }
			}
			set_variable = { ENG_Paramilitary_state_productivity_growth = -0.20 }
			set_variable = { ENG_Paramilitary_local_factory_sabotage = 0.20 }
			set_variable = { ENG_Paramilitary_required_garrison = 15 }
		}

		else_if = {
			limit = {
				check_variable = { ENG_north_irish_agitation > 44 }
				check_variable = { ENG_north_irish_agitation < 60 }
			}
			set_variable = { ENG_Paramilitary_state_productivity_growth = -0.25 }
			set_variable = { ENG_Paramilitary_local_factory_sabotage = 0.35 }
			set_variable = { ENG_Paramilitary_required_garrison = 25 }
		}

		else_if = {
			limit = {
				check_variable = { ENG_north_irish_agitation > 59 }
				check_variable = { ENG_north_irish_agitation < 80 }
			}
			set_variable = { ENG_Paramilitary_state_productivity_growth = -0.45 }
			set_variable = { ENG_Paramilitary_local_factory_sabotage = 0.45 }
			set_variable = { ENG_Paramilitary_required_garrison = 45 }
		}

		else_if = {
			limit = {
				check_variable = { ENG_north_irish_agitation > 79 }
				check_variable = { ENG_north_irish_agitation < 101 }
			}
			set_variable = { ENG_Paramilitary_state_productivity_growth = -0.75 }
			set_variable = { ENG_Paramilitary_local_factory_sabotage = 0.60 }
			set_variable = { ENG_Paramilitary_required_garrison = 65 }
		}

		multiply_variable = { ENG_Paramilitary_state_productivity_growth = ENG_agitation_penalty_mult }
		multiply_variable = { ENG_Paramilitary_local_factory_sabotage = ENG_agitation_penalty_mult }
		multiply_variable = { ENG_Paramilitary_required_garrison = ENG_agitation_penalty_mult }
	}
}

# Reorganise every British subject sitting on a generic MD subject tier onto the
# matching Pax colonial tier (closest autonomy band, preserving puppet status):
# associated -> Dominion, satellite -> Colony, puppet_state/autonomous -> Puppet.
# Colour follows GAME_RULE_allow_colored_puppets. Subjects already on a Pax tier or a
# bespoke ladder (devolution, ADS) are left untouched. Run once at the focus, again on
# every new puppet (on_puppet), and weekly as a backstop, so war-puppets convert too.
eng_convert_subjects_to_colonial = {
	every_subject_country = {
		limit = {
			OR = {
				has_autonomy_state = autonomy_associated_state
				has_autonomy_state = autonomy_associated_state_colored
				has_autonomy_state = autonomy_satellite_state
				has_autonomy_state = autonomy_satellite_state_colored
				has_autonomy_state = autonomy_puppet_state
				has_autonomy_state = autonomy_puppet_state_colored
				has_autonomy_state = autonomy_autonomous_state
				has_autonomy_state = autonomy_autonomous_state_colored
			}
		}
		if = {
			limit = {
				OR = {
					has_autonomy_state = autonomy_associated_state
					has_autonomy_state = autonomy_associated_state_colored
				}
			}
			if = {
				limit = { has_global_flag = GAME_RULE_allow_colored_puppets }
				ENG = { set_autonomy = { target = PREV autonomy_state = autonomy_dominion_colored freedom_level = 0.85 } }
			}
			else = {
				ENG = { set_autonomy = { target = PREV autonomy_state = autonomy_dominion freedom_level = 0.85 } }
			}
		}
		else_if = {
			limit = {
				OR = {
					has_autonomy_state = autonomy_satellite_state
					has_autonomy_state = autonomy_satellite_state_colored
				}
			}
			if = {
				limit = { has_global_flag = GAME_RULE_allow_colored_puppets }
				ENG = { set_autonomy = { target = PREV autonomy_state = autonomy_colony_colored freedom_level = 0.60 } }
			}
			else = {
				ENG = { set_autonomy = { target = PREV autonomy_state = autonomy_colony freedom_level = 0.60 } }
			}
		}
		else = {
			if = {
				limit = { has_global_flag = GAME_RULE_allow_colored_puppets }
				ENG = { set_autonomy = { target = PREV autonomy_state = autonomy_puppet_colored freedom_level = 0.30 } }
			}

# Recalculate the State of the Empire dynamic modifier. Each stat starts at its
# "Empire Strikes Back" value and linearly inverts as more former British Empire
# territory is reconquered: value = start * (1 - 2f), where f is the fraction of
# the 543 historical Empire states ENG now controls. Bureaucracy cost instead
# climbs from 0 to its cap as f rises. Run on completion of the focus and weekly.
eng_update_state_of_the_empire = {
	set_temp_variable = { ENG_soe_owned = 0 }
	every_owned_state = {
		limit = { is_any_eng_empire_state = yes }
		add_to_temp_variable = { ENG_soe_owned = 1 }
	}
	# f = owned / 543, clamped to [0,1]
	set_temp_variable = { ENG_soe_f = ENG_soe_owned }
	divide_temp_variable = { ENG_soe_f = 543 }
	clamp_temp_variable = { var = ENG_soe_f min = 0 max = 1 }
	# inversion factor i = 1 - 2f, runs +1 (start) -> -1 (full inverse)
	set_temp_variable = { ENG_soe_inv = ENG_soe_f }
	multiply_temp_variable = { ENG_soe_inv = -2 }

# Pax Britannica regional consolidation (Tasks 7-9).
# When ENG (the Pax overlord) beats a region's PRIMARY nation it is re-established
# as a Dominion anchor with its colonial flag; every other conquered nation in the
# region is then merged into that primary (states + cores). Driven by on_annex /
# on_puppet for immediacy and an on_monthly_ENG ownership backstop.
# Per-region rather than parameterised because the membership/state triggers and the
# primary tag cannot be passed as arguments (mirrors eng_pax_antagonize_<region>).

eng_pax_consolidate_north_africa = {
	# Anchor EGY as a Dominion once ENG has beaten it, then fold the region's
	# territory into it. Run in ENG scope; gated so it is idempotent.
	if = {
		limit = {
			NOT = { has_country_flag = eng_pax_north_africa_anchored }
			OR = {
				EGY = { is_subject_of = ENG }
				AND = {
					NOT = { country_exists = EGY }
					any_state = { is_core_of = EGY is_owned_by = ENG }
				}
			}
		}
		if = {
			limit = { NOT = { country_exists = EGY } }
			release_puppet = EGY
		}
		if = {
			limit = { has_global_flag = GAME_RULE_allow_colored_puppets }
			set_autonomy = { target = EGY autonomy_state = autonomy_dominion_colored }
		}
		else = {
			set_autonomy = { target = EGY autonomy_state = autonomy_dominion }
		}
		EGY = { set_cosmetic_tag = EGY_british_colony }
		set_country_flag = eng_pax_north_africa_anchored
	}
	# Once the anchor is held, fold the region's conquered territory into EGY.
	if = {
		limit = { EGY = { is_subject_of = ENG } }
		every_owned_state = {
			limit = {
				is_eng_empire_north_africa_state = yes
				NOT = { is_core_of = EGY }
			}
			add_core_of = EGY
			transfer_state_to = EGY
		}
	}
}

eng_pax_consolidate_caribbean = {
	# Anchor JAM as a Dominion once ENG has beaten it, then fold the region's
	# territory into it. Run in ENG scope; gated so it is idempotent.
	if = {
		limit = {
			NOT = { has_country_flag = eng_pax_caribbean_anchored }
			OR = {
				JAM = { is_subject_of = ENG }
				AND = {
					NOT = { country_exists = JAM }
					any_state = { is_core_of = JAM is_owned_by = ENG }
				}
			}
		}
		if = {
			limit = { NOT = { country_exists = JAM } }
			release_puppet = JAM
		}
		if = {
			limit = { has_global_flag = GAME_RULE_allow_colored_puppets }
			set_autonomy = { target = JAM autonomy_state = autonomy_dominion_colored }
		}
		else = {
			set_autonomy = { target = JAM autonomy_state = autonomy_dominion }
		}
		JAM = { set_cosmetic_tag = JAM_british_colony }
		set_country_flag = eng_pax_caribbean_anchored
	}
	# Once the anchor is held, fold the region's conquered territory into JAM.
	if = {
		limit = { JAM = { is_subject_of = ENG } }
		every_country = {
			limit = {
				is_subject_of = ENG
				eng_pax_is_caribbean_secondary = yes
			}
			every_owned_state = {
				add_core_of = JAM
				transfer_state_to = JAM
			}
		}
		every_owned_state = {
			limit = {
				is_eng_empire_caribbean_state = yes
				NOT = { is_core_of = JAM }
			}
			add_core_of = JAM
			transfer_state_to = JAM
		}
	}
}
